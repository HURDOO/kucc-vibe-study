# PROJECT_BRIEF — 나만의 PDF 도구

## 누가, 언제 사용하나요?

강의자료에서 필요한 페이지만 남기고 싶은 대학생이 사용합니다.

## 만들 것

내 컴퓨터의 브라우저에서 실행하는 작은 PDF 편집기입니다.

## 필수 기능

1. 컴퓨터에서 PDF 파일을 선택해 엽니다.
2. 각 페이지를 구분하고 미리 볼 수 있습니다.
3. 필요 없는 페이지를 선택해 삭제합니다.
4. 남은 페이지를 새 PDF 파일로 내려받습니다.

## 사용 조건

- PDF는 브라우저 안에서 처리하며 외부 서버로 업로드하지 않습니다.
- 원본 파일은 그대로 두고 결과를 새 파일로 저장합니다.
- 한국어 화면으로 만듭니다.
- 처리 중인 상태와 실패 이유를 알아보기 쉽게 표시합니다.
- 모든 페이지를 삭제한 경우에는 저장할 수 없도록 안내합니다.

## 이번에 만들지 않을 것

로그인, 온라인 파일 보관, 결제, PDF 본문 글자 수정.

## 완성 확인

- 3쪽 이상인 PDF를 열고 두 번째 페이지를 삭제합니다.
- 결과 파일을 내려받아 다시 엽니다.
- 선택한 페이지가 빠지고 나머지 페이지와 순서가 유지되는지 확인합니다.
- 원본 파일이 그대로 남아 있는지 확인합니다.
