## 1. 프로젝트 한 줄 소개

대학생이 사용할 간단한 PDF 편집기. 간단한 필기 기능, 페이지 추가/순서변경/삭제 등 기본 기능을 MVP로 만드는 것을 목표로 한다.

## 2. 배경과 문제

- 현재 겪는 문제: 크롬에 있는 기본 pdf 뷰어는 편집도 안되고 불편하다.
- 이 문제가 중요한 이유: 컴퓨터에서 바로 pdf를 수정하기 힘들다.
- 지금 사용하는 대안과 그 한계: 편집하려면 pdf를 패드로 옮겨서 노트 앱에서 불러와서 다시 추출해서 옮겨와야 한다.

## 3. 대상 사용자

- 주요 사용자: 나!
- 사용자의 상황과 숙련도: 평범한 대학생. 약 50페이지 내외의 강의자료를 사용
- 가장 중요한 사용자 요구: 간단한 pdf 편집은 컴퓨터에서 끝내고 싶어

## 4. 첫 번째 사용 가능 버전(MVP)

### 핵심 기능

1. 간단한 필기 기능
2. pdf 페이지 추가, 삭제 및 순서변경
3. 여러 pdf 합치기

### 이번 MVP에서 제외할 기능
- 연필 색상 및 굵기 등 커스터마이징
- 다른 pdf에서 일부 페이지만 선택적으로 가져오기. 일단 모두 가져온 다음 선택해서 지우는걸로 MVP에선 대체한다
- 실행 취소 (Ctrl+Z)
- 브라우저에 자동 저장
- 로그인, 클라우드 연동 등 서버가 필요한 기능
- 모바일 지원

### 대표 사용 흐름

1. 첫 화면에서 사용자가 pdf 파일을 '찾아오기'를 눌러 불러오거나, 드래그 앤 드롭으로 로드한다.
2. pdf가 로드되며, 사용자는 왼쪽 목차(페이지 미리보기)를 통해 페이지를 편하게 관리할 수 있다. 빈 페이지를 추가하거나, 다른 pdf 내용을 불러오거나, 페이지 순서를 바꾸거나, 삭제할 수 있다.
3. 사용자가 연필 모드를 활성화한 상태에서는, pdf의 마우스로 그린 부분에 필기가 남는다. 지우개 모드를 활성화한 상태에서는, 마우스가 닿은 필기가 지워진다.
4. 그렇게 편집한 pdf를 추출 버튼을 눌러 저장할 수 있다.
