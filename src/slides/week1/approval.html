승인 모드

승인 요청

매번 사용자에게 묻기

명령어를 실행할 때마다 "실행해도 될까요?"라고 확인합니다. 가장 안전하지만, 자주 멈춥니다.

나 대신 승인

다른 GPT가 대신 검사

별도의 GPT가 명령어와 대화 전체 맥락을 보고 실행해도 되는지 판단합니다.

예시 · 프로젝트를 다 만든 뒤, 우리가 시키지도 않았는데 GPT가 앞서나가 코드를 인터넷에 올리려고 할 때가 있어요.
→ 검사하는 GPT가 "사용자가 업로드를 아직 허용하지 않음"이라며 실행을 차단합니다.

두 번째는 '자동 승인' 기능입니다. '승인 요청' 모드에서는 명령어를 실행할 때마다 사용자에게 묻습니다. '나 대신 승인'을 선택하면 다른 GPT를 별도로 띄워 이 명령어를 실행해도 되는지 AI가 직접 검사합니다. 명령어만 보는 게 아니라 전체 대화 맥락을 봐요. 예를 들어 배포할 때 우리가 올리라고 한 적이 없는데 GPT가 먼저 올리려 하면, 이 서브 GPT가 '사용자가 업로드를 아직 허용하지 않음' 같은 메시지와 함께 차단합니다.
