// ② 도구(Tool)

정해진 형식으로 출력하게 하면?

# GPT의 출력
tool: 파일 쓰기
file name: main.py
content:
s = input()
print(s, "Hello World!")

→

이 형식을 읽어서
실제로 파일을 쓰는 프로그램

GPT가 형식대로 말하면, 프로그램이 그대로 실행 → LLM이 직접 파일을 만든 것과 같아진다

그런데 AI에게 특정한 출력 형식대로 출력하라고 지침을 주는 겁니다. 그리고 이런 형식대로 나온 출력을 받아서 실제로 파일을 쓰는 동작을 하는 프로그램을 만드는 겁니다. 그러면 LLM이 직접 파일을 생성하고 거기에 코드를 쓰는 것과 같게 되죠.
