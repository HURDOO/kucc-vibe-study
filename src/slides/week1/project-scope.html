// Codex의 기능 ①

"프로젝트" - 수정해도 되는 폴더를 정해주기

  • 폴더를 지정하면 Codex는 그 폴더 안에서만 작동합니다
  • 지정한 폴더를 샌드박스 범위 안에 넣어주는 것
  • 폴더 밖에서 무언가 하려면 별도 승인이 필요합니다

바탕화면/
├─ 과제/                   승인 필요
├─ 사진/                   승인 필요
└─ kucc-vibe-study-week1/  자유롭게

Codex는 도구 외에도 몇 가지 기능을 제공합니다. 첫 번째는 '프로젝트' 기능입니다. 폴더를 지정해두면 Codex는 그 폴더 안에서만 작동하고, 밖에서 무언가를 하려면 별도의 승인이 필요합니다. 샌드박스 범위 안에 이 폴더를 넣어줘서, Codex가 수정해도 되는 폴더의 범위를 정해주는 거죠.
