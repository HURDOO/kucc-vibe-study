붙여넣기 전에 세 가지 설정을 확인하세요

1

왼쪽 위

ChatGPT가 아닌 Codex로 설정되어 있는지 확인

2

입력창 왼쪽 아래

'승인 요청' 대신 '나 대신 승인'으로 설정

3

입력창 오른쪽 아래

모델은 GPT 6.1 Sol,
추론 수준은 Extra High로 설정

프롬프트를 붙여넣기 전에 세 가지 설정을 함께 확인합니다. ① 왼쪽 위가 ChatGPT가 아닌 Codex로 되어 있는지, ② 입력창 왼쪽 아래 권한을 '승인 요청' 대신 '나 대신 승인'으로, ③ 입력창 오른쪽 아래 모델을 GPT 6.1 Sol, 추론 수준을 Extra High로. 그다음 사이트에 '프롬프트 모음집'이 있습니다. 거기에서 첫 번째 프롬프트를 복사해서 붙여넣고 엔터를 누르세요. 에이전트가 알아서 git clone을 진행합니다. 승인 요청이 뜨면 허락해 주세요.
