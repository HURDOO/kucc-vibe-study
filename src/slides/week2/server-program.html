서버

문을 열어두고 기다리다가, 요청이 오면 응답하는 프로그램

사실 서버 하면 뭔가 엄청 커다란 컴퓨터가 있고 거기에서 대단한 게 돌아갈 것 같은데, 사실 서버는 그냥 프로그램이랑 다르지 않거든요. 크롬을 생각해 봅시다. 우리가 네이버에 접속하면 크롬이 네이버 서버에 연결해서 사이트를 받아오죠. 카톡도 마찬가지로, 카톡 앱이 카톡 서버에 접속해서 채팅 내용을 받아옵니다. 둘 다 연결을 먼저 '요청'합니다. 이런 역할을 하는 프로그램을 클라이언트라고 불러요. 반면 서버는 인터넷에 연결되어 문을 열어두고 있다가, 클라이언트의 요청이 들어오면 그 요청에 '응답'하는 프로그램입니다.
