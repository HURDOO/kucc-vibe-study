몇 명이 다녀갔는지 세어 보세요. 그리고… 노트북을 덮으면 어떻게 될까요?

다른 사람 커뮤니티에 글을 다 남겼으면, 이제 내 posts.csv를 엑셀로 열어 보세요. 친구들이 자기 폰이나 노트북에서 쓴 글이 전부 내 노트북 파일에 쌓여 있을 거예요. 서버가 내 컴퓨터라는 게 이걸로 확실히 보이죠. 몇 명이 다녀갔는지 세어 보세요. 보너스로, 비밀번호 열은 서버 파일에는 있어야 하지만, Network 탭에서 글 목록을 받아오는 응답에는 없어야 해요. 만약 응답에 비밀번호가 섞여 있다면 버그를 찾은 겁니다. 아까 로그인 퀴즈에서 배운 걸 내 결과물로 검사해 보는 거예요. 확인 후 엑셀은 꼭 닫아 주세요.
