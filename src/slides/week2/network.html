이번에는 Network 탭에 들어가 볼까요. F12를 눌러 개발자 도구를 열고 Network 탭을 연 상태에서 내 커뮤니티에 글을 하나 써 보세요. 요청이 하나 새로 생깁니다. 클릭해 보면 내가 보낸 글 내용과, 서버가 돌려준 응답을 볼 수 있어요. 그리고 posts.csv를 메모장으로 열어 보면 맨 아래에 방금 쓴 글이 한 줄 추가되어 있습니다. 브라우저가 요청하고, 서버가 파일에 쓰고, 응답하는 과정이 전부 눈에 보이는 거죠. 사진이나 동영상도 이렇게 서버에서 받아옵니다. (LMS 썰) 먼저 끝난 분들은 댓글이나 좋아요 기능을 추가해 보세요.
