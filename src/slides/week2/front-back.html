// ④ 프론트엔드와 백엔드

프론트엔드

사용자의 브라우저에서 실행

화면 · 버튼 · 입력창

지금 만드는 폴더 (예시)

kucc-vibe-study-week2/
├─ public/
│  ├─ index.html  → 브라우저로
│  └─ app.js      → 브라우저로
├─ server.js     ■ 서버에 남음
└─ posts.csv     ■ 서버에 남음

백엔드

서버(지금은 내 노트북)에서 실행

글 저장 · 판단 · 비밀 보관

파일 이름은 예시예요. 내 폴더에선 어떤 파일이 어느 쪽일까요? 구현이 끝나면 직접 찾아보세요.

에이전트가 작업하면서 프론트엔드, 백엔드라는 말을 자주 할 거예요. 차이는 딱 하나, 어디서 실행되느냐입니다. 프론트엔드는 사용자의 브라우저에서 실행되는 코드예요. 화면, 버튼, 입력창 같은 것들이죠. 백엔드는 서버에서 실행되는 코드고, 글을 저장하거나 판단하거나 비밀을 보관합니다. 지금 만드는 폴더로 보면, public 폴더 안의 파일들은 사용자의 브라우저로 보내지고, server.js와 posts.csv는 서버, 지금은 내 노트북에 그대로 남아 있어요. 파일 이름은 에이전트마다 다르니, 구현이 끝나면 자기 폴더에서 어떤 파일이 어느 쪽인지 찾아보세요.
