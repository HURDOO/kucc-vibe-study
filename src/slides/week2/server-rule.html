> 이건 서버에서 처리해줘

바이브코딩 보안 사고 대부분은, 서버가 지켜야 할 것과
클라이언트에 보내도 되는 것을 구분하지 못해서 생깁니다.

바이브 코딩에서 대부분의 보안 사고는 이렇게 일어납니다. 서버에서 지켜야 하는 데이터와, 클라이언트에게 공유해도 되는 데이터를 구분하지 못해서 발생해요. 비밀번호, API 키, 게임 점수 판정, 관리자 권한처럼 믿어야 하는 건 서버에 둬야 합니다. 원리를 다 알 필요는 없어요. 에이전트에게 '이건 서버에서 처리해줘'라고 말할 수 있으면 충분합니다.
